contains six native archives and their checksums, built from `5c1b4cd` by successful
run `35035075672`. Core, client and CLI crates version 0.1.0 were published to
crates.io in dependency order. The distributable source is unchanged between
that candidate and the deployment commit.

Verified public installations on macOS ARM64:

- Exact documented curl/bash command, SHA-256 verification, executable version,
  embedded MIT notice, current registry update check, help and unauthenticated status.
- `cargo install silicon-honeycomb-cli --version '=0.1.0' --locked` from crates.io,
  followed by the same command checks.
- Default installer registration of the real macOS launchd updater in an isolated
  installation. Its LaunchAgent and temporary home were removed after verification.
- Released native CLI reads the production IAM metadata and catalog successfully.

All six native runners tested the Rust workspace, Cargo source installation,
release executable and license notice. Public registry installation above was
performed on macOS ARM64; it is not a claim of separately repeating that public
download on every supported OS.

## Live base acceptance

- Valid HTTPS on all three domains. Caddy's first certificate download received
  an ACME 404; its automatic retry obtained the production certificate successfully.
- Backend health, contract discovery and public catalog return 200; unauthenticated
  backend identity returns 401. The production catalog is empty.
- Both frontends serve built assets and the correct per-site configuration.
  Anonymous session reads return `authenticated: false` with `private, no-store`.
- Browser inspection confirms the library's empty state and console login gate,
  with the requested paper/blue/serif Interface styling.
- Both sign-in routes redirect to the correct IAM application and same-site
  callback. State cookies are HttpOnly, Secure and SameSite=Lax.
- Invalid callbacks return 400; missing-origin writes return 403. Valid same-origin
  application creation requests without a session return 401.

## Remaining acceptance

This rollout establishes the hosted base and CLI distribution. It does not prove
authenticated application creation, real private catalog visibility, public review
activation, shared test lifecycles, or live archive/logo delivery. IAM's required
membership grants and remaining contracts are documented in
`docs/IAM-CONTRACT-REVIEW.md`. Briefcase setup is explicitly deferred until after
the base. Complete those integrations and their authenticated end-to-end tests
before describing the full original product goal as complete.
