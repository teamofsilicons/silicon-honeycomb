| Term | Meaning |
| --- | --- |
| Application | Permanent organization-owned identity and accepted/requested configuration. |
| App ID | `org>local-handle`; quote it in shell commands. |
| Archive / package | A validated `.tar.gz` containing a manifest and native target payloads. |
| Release | Immutable package version with recorded hash and byte length. |
| Library | Discovery surface for public and authorized private applications. |
| Console | Authenticated administration and publication workflows. |
| Carbon / Silicon | IAM account types; authorization still depends on current policy and roles. |
| Scope | Permission requested by an app and accepted through IAM/provider policy. |
| OBO | On-behalf-of delegated access for a particular user and selected organization. |
| Requested configuration | The change an administrator submitted. |
| Effective configuration | State currently accepted by IAM for runtime use. |
| Revision | Optimistic concurrency counter for a particular resource. |
| Idempotency key | Identifier that makes exact retries recover the same logical mutation. |
| Operation | Durable progress/recovery record for a cross-service change. |
| Testing environment | Shared isolated context coordinated across participating services. |
| Generation | Lifecycle epoch used to reject stale testing work. |
| Step-up assertion | Fresh IAM proof bound to a sensitive action/resource. |
| Bundle | Honeycomb-owned grouping design; complete management workflow is not available in this release. |
